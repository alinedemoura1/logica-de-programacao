# 🔢 Calculadora de Partidas Rankeadas
Projeto desenvolvido para o segundo desafio de lógica de programação da **DIO**.

## ⚙️ Tecnologias Utilizadas
- JavaScript

## 🧠 Conceitos Aplicados
- Variáveis
- Funções
- Estruturas de Decisão (if, else if e else)

## 📝 O que o código faz?
Calcula o saldo de partidas rankeadas e categoriza o nível do herói com base em seu desempenho de vitórias.
