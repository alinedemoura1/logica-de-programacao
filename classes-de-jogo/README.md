# ⚔️ Escrevendo as classes de um Jogo
Projeto desenvolvido para o terceiro desafio de lógica de programação da **DIO**.

## ⚙️ Tecnologias Utilizadas
- JavaScript

## 🧠 Conceitos Aplicados
- Classes e Objetos
- Funções
- Estruturas de Decisão (if, else if e else)

## 📝 O que o código faz?
Implementa uma classe de herói que automatiza a escolha e exibição do tipo de ataque conforme a classe selecionada.
