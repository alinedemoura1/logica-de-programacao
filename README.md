# 💻 Desafios de Lógica de Programação - DIO

Este repositório contém as soluções dos desafios da formação Lógica de Programação com Javascript, da **DIO**.

## 📂 Projetos incluídos:
1. **Classificador de Nível de Herói**: Utiliza estruturas de decisão para ranquear heróis.
2. **Calculadora de Partidas Rankeadas**: Implementa lógica de funções para calcular o saldo líquido de vitórias e determinar o ranking do jogador.
3. **Classes de um Jogo**: Utiliza Classes e Objetos para estruturar um sistema dinâmico de ataques baseado no tipo de herói.
